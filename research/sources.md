# Sources: The Master Bibliography

**Research date:** 2026-11-01

Every citation in this library, in one place, with the section of the repository
that uses it. Links are DOIs where a DOI exists and arXiv or publisher URLs
otherwise.

**On reliability.** Bibliographic entries here were checked against the
publisher, DOI registry, or arXiv page. Product documentation was read from each
vendor's own pages on the date above and is cited in
[03-agent-native-memory.md](03-agent-native-memory.md) rather than repeated here.
Where a widely circulated citation is wrong — a wrong year, wrong journal, wrong
first author — the correct form is given and the common error is noted in
[sources-corrections.md](sources-corrections.md).

## 8. Product documentation

Nineteen products, ~45 documentation pages, read 2026-11-01. Full URLs are listed
at the end of [03-agent-native-memory.md](03-agent-native-memory.md), where each
is attached to the claim it supports. They are not repeated here because they
change frequently and the per-product context is what makes them useful.

**A note on link rot.** During this research, four documentation surfaces moved
or disappeared: Windsurf's memory docs (folded into Devin), Roo Code's memory
docs (withdrawn entirely), OpenAI's help centre (moved to `learn.chatgpt.com`),
and Gemini CLI's docs host. Any citation to the older URLs will break. Where a
product's documentation could not be retrieved at all, the product was dropped
rather than reconstructed from third-party write-ups — see
[03-agent-native-memory.md](03-agent-native-memory.md) §8.
