# 认知架构：把记忆当作心智的一个部件

**研究日期：** 2026-11-01

这份文档所覆盖的传统，想做的是 LLM 领域现在正在无意中做的事：在**一个形式系统里**说清记忆如何参与思考。它的成果大多被当下的 agent 记忆研究忽略了，这是一种损失——因为它做出了两个发现，而 LLM 领域正在重新发现它们。

第一个：**记忆无法独立于使用它的控制器来定义。** 一个存储的设计只有在相对于某个检索策略时才有意义，而检索策略只有在相对于任务结构时才有意义。

第二个：**记忆里真正有意思的部分是"可及性的算术"**——每个条目一个标量，随使用而更新，把近因、频率、情境匹配组合成一个控制器可以跟阈值比较的数字。其余都是簿记。

---

## 1. 这个传统为什么存在

1970 到 1990 年间，三个纲领撞上了同一个问题。

**信息加工心理学**（Atkinson & Shiffrin、Newell & Simon）有带箭头的部件模型，但没有定量预测。

**人工智能**有能搜索的程序，但不能记忆——每次运行都从头开始，而加知识反而让它变慢（*效用问题*：每条新规则或新事实都增加匹配时间）。

**数学心理学**有对孤立现象（遗忘曲线、反应时分布）的精确模型，但它们拼不成一个系统。

认知架构是试图造出一个能产生这些现象的人造物的努力。它们的架构承诺——固定的一组模块、一个中央瓶颈、一个靠模式匹配访问的陈述性存储、一个由条件—动作规则组成的程序性存储——被证明足够耐久，以至于这些词汇活进了现代 agent 系统，哪怕机制没有。

**值得保留的组织性洞见。** 三个架构收敛到同一个分解上，而这个分解不是现代 agent 框架用的那个：

| 层 | 生物学的说法 | 架构的说法 | 现代 agent 的对应物 |
|---|---|---|---|
| **长时陈述性** | 语义 + 情景 | 激活加权的块存储 | 向量库 + 记忆文件 |
| **工作记忆** | 容量有限的缓冲 | 当前目标栈 + 匹配到的块 | 上下文窗口 + todo 列表 |
| **程序性** | 技能 | 产生式规则 | 工具定义、代码 |
| **元认知** | 前额叶控制 | 冲突消解、目标管理 | planner / critic 循环 |

现代技术栈有第一、第二、第四层。它**没有独立于工具的程序性层**——而这正好是技能库（Voyager、Anthropic 的 Agent Skills）正在填的缺口，也是它们会腐烂的原因：产生式系统有一个冲突消解策略，技能库没有。

## 2. ACT-R：可及性的算术

Anderson, J. R. (2007). *How Can the Human Mind Occur in the Physical Universe?*
Oxford University Press.

Anderson, J. R., Bothell, D., Byrne, M. D., Douglass, S., Lebiere, C., & Qin,
Y. (2004). An integrated theory of the mind. *Psychological Review*, 111(4),
1036–1060. DOI
[10.1037/0033-295X.111.4.1036](https://doi.org/10.1037/0033-295X.111.4.1036)。

ACT-R 对记忆设计来说是最重要的一个，因为它是唯一把记忆归约成**一个可计算的量**的。

**基础激活值。** 每个块 *i* 有一个激活值

```
B_i = ln( Σ_j t_j^(-d) )
```

对它的 *j* 次过往使用求和，其中 *t_j* 是第 *j* 次使用距今的时间，*d* ≈ 0.5。这就是 Anderson & Schooler 的需求概率结果在闭式下的形式：频繁且近期的条目激活高，而且衰减是**幂律**，不是指数。

**为什么这比看起来更重要。** 有三个性质需要拆开讲。

*它是对历史的求和，不是对最后一次写入的函数。* 条目的全部访问历史都在这个数里。一个 `last_accessed` 列不是这个。

*它不依赖全局时钟。* 没有一个施加于所有条目的衰减常数；每个条目按自己使用的间隔以不同速率衰减。

*它有解释。* 激活值近似是需求的对数几率。那是一个**校准过**的分数，不是任意的排序启发式——这意味着卡在它上面的阈值是有意义的（"只在 P(需要) > 0.3 时检索"），而多数系统的余弦阈值不是。

**部分匹配与噪声。** 检索不是取最大。激活值要与线索上的匹配分数相加，再加上 logistic 噪声；总分最高且过阈值的块被取出，如果没有块过阈值，系统**优雅地失败**，而不是从一堆坏结果里返回最好的那个。

这里有当前系统非常需要的两个想法：检索是一个**带弃权选项的阈值决策**；以及**随机化**检索，它让系统去探索，而不是永远确定性地返回同一个 top-1。

**扩散激活。** 相关的块互相启动，所以一个线索能到达不直接匹配它的材料。这就是 GraphRAG 和 HippoRAG 重新推导出来的图邻域扩展，只有一点不同：ACT-R 里扩散是有界且随距离衰减的，所以不会爆掉。现代图检索通常缺一个有原则的界。

**产生式编译。** 反复通过检索加推理解决的问题会**编译**成单条产生式规则——系统不再需要那条记忆，因为程序已经吸收了它。这就是"抽象要求丢弃实例"（Nørby 2015）的可运行版本：实例被丢掉，*正因为*规则取代了它。

对 agent 记忆来说，这是整个文献里最欠实现的一个想法。一个记忆系统应该有一条路径，让频繁被检索的情节变成一个**过程**，从此不再被检索。几乎没有一个系统有；它们永远检索同一批情节，然后把这种堆积叫"学习"。

## 3. SOAR：记忆是僵局的副产品

Laird, J. E. (2012). *The Soar Cognitive Architecture*. MIT Press.

Laird, J. E., Newell, A., & Rosenbloom, P. S. (1987). SOAR: An architecture for
general intelligence. *Artificial Intelligence*, 33(1), 1–64.
DOI [10.1016/0004-3702(87)90050-7](https://doi.org/10.1016/0004-3702(87)90050-7)。

SOAR 的写入策略是它最有意思的地方，因为它是一个关于**何时学习**的决策，不是关于存什么。

**僵局驱动的学习。** 当当前的操作符选择进行不下去——没有操作符被提议，或者几个并列——SOAR 建立一个**子状态**来消解僵局。消解的结果被**组块化**（chunking）：编译出一条新产生式规则，下次在同样局面下直接触发。

所以写入触发条件是**既有策略的失败**。不是"来了新信息"。不是"时间过去了"。不是"用户说了要记住"。系统*只在*它当前知识不够用的时候写——这正好是预测误差准则，独立地、比多巴胺类比早四十年就到达了。

**后果是一个关于记忆规模的强主张。** 因为组块只在僵局处产生，而每个组块消解掉一个僵局，知识库的增长与*遇到的新奇局面数*成正比，与经验时长无关。组块化是**策略的压缩**，不是事件的日志。

**SOAR 中的情节记忆**（Nuxoll & Laird, 2007, *Integrating episodic memory into a cognitive architecture*, *Advances in Cognitive Systems*）在决策点存工作记忆状态的快照，按时间和**任务**而非时钟打标签。检索靠线索，而且——这个设计选择值得抄——情节**从不直接被用来改变行为**；它们用于解释、用于从单个过往案例学习、用于内省。这种分离（情节存储服务于*学习者*，不服务于*行动者*）在我所知的任何 LLM agent 记忆系统里都不存在，而这大概就是 agent 情节记忆如此不可靠的原因：它被用在了错误的岗位上。

**语义记忆**在 SOAR 里是一张长期事实的图，带**基于激活的遗忘**和类似于 ACT-R 的**基础学习**规则。三个存储——程序性（规则）、语义（事实）、情节（快照）——共用一个检索机制但写入触发条件不同。再一次：一个当前 agent 框架没有的记忆类型系统。

## 4. 全局工作空间与绑定问题

Baars, B. J. (1988). *A Cognitive Theory of Consciousness*. Cambridge University
Press.

Dehaene, S., Kerszberg, M., & Changeux, J.-P. (1998). A neuronal model of a
global workspace in effortful cognitive tasks. *PNAS*, 95(24), 14529–14534.
DOI [10.1073/pnas.95.24.14529](https://doi.org/10.1073/pnas.95.24.14529)。

全局工作空间理论回答了一个"存储—检索"框架回答不了的问题：**来自不同专用系统的条目，怎么变成一个表征？** 它的答案是架构性的——一个容量有限的工作空间，许多无意识的专用处理器竞争着往里写，写进去的内容再广播回所有处理器。

对记忆设计有两个后果。

**工作空间是一个瓶颈，而这正是要点。** 容量限制迫使竞争，而竞争才让广播有意义——只有最相关的内容能到达整个系统。一个工作空间无限的系统没有选择，因此也没有显著性。

**广播是绑定的机制。** Baddeley 的情景缓冲器是同一想法的小尺度版本；transformer 里的注意力在功能上也是（尽管机制上不是）。"检索 top-k 然后拼接起来"作为记忆架构让人感觉不对，原因就是拼接*不是*绑定：流水线里没有任何东西决定这些条目共同构成一个情境。

**确实做了绑定的 AI 对应物**是 KV cache，以及生成时对它施加的注意力——那是模型自己的工作记忆。这就引出一条多数 agent 框架忽略的设计规则：**检索应该把材料放到能被共同注意的位置，而不只是追加到一个列表上。** 两段从不相注意的检索结果，是两条记忆，不是一条。

Dehaene 的 *Consciousness and the Brain*（2014, Viking）是可读的版本，它把"点火 / 阈值"框架讲清楚了：工作空间的进入在过阈值之后是**全或无**的，这又是一个支持阈值化检索而非 top-k 的论据。

## 5. 记忆增强神经网络

这条线试图**学出**记忆而不是工程化它。它是当前这一代的直接前身，而它的失败很有教育意义。

**Graves, A., Wayne, G., & Danihelka, I. (2014).** Neural Turing Machines.
arXiv:[1410.5401](https://arxiv.org/abs/1410.5401)。

一个控制器网络通过可微注意力读写一块外部记忆矩阵。关键的招式：读写头既是**基于内容的**也是**基于位置的**，写头带有**先擦后加**操作，所以网络学到的是*覆写什么*，而不只是*追加什么*。

"先擦后加"值得点名。它是"一个能被修改的记忆"的最小接口，而多数向量库没有它：它们只做加法。按 key 做 `upsert` 不是同一件事，因为 key 必须提前知道，而 NTM 的擦除向量是从内容算出来的。

**Graves, A., Wayne, G., Reynolds, M., Harley, T., Danihelka, I., Grabska-
Barwińska, A., … Hassabis, D. (2016).** Hybrid computing using a neural network
with dynamic external memory. *Nature*, 538(7626), 471–476.
DOI [10.1038/nature20101](https://doi.org/10.1038/nature20101)。

可微神经计算机（DNC）加了**基于使用情况的分配**（记住哪些槽是空的、以及它们最近被使用的顺序）和**时间链接矩阵**，记录记忆被写入的顺序，使控制器能按顺序遍历它们。

时间链接矩阵是最重要的一项，而它在现代系统里几乎不存在。它是一份*来源排序*：第 N 条记忆知道紧挨着它写入的前一条和后一条是什么。这换来顺序回忆，更重要的是，它使人可以在没有时间戳列和范围查询的情况下问"这条前后发生了什么"——结构就在记忆里。

DNC 同时也是一个诚实的警示故事。它在合成任务上有效（bAbI、图遍历、结构化输入上的问答），但没有迁移到开放域。通常得出的教训——"学出来的记忆不可扩展"——太强了。更窄的教训是：**一个梯度训练出来的记忆没有稳定接口**。因为写入策略是与其他一切联合学出来的，所以没办法检视它，没办法按策略从它里面删除，也没办法审计到底写进去了什么。而这些正是 2026 年的系统需要、2016 年的系统不需要的东西。

**Weston, J., Chopra, S., & Bordes, A. (2015).** Memory networks.
arXiv:[1410.3916](https://arxiv.org/abs/1410.3916).
Sukhbaatar, S., Weston, J., & Fergus, R. (2015). End-to-end memory networks.
arXiv:[1503.08895](https://arxiv.org/abs/1503.08895)。

Memory Networks 把记忆与推理分开：把句子存进槽数组，然后在回答之前对槽做多轮 **hop** 的注意力。这个多跳回路是迭代检索（IRCoT、Self-RAG、HippoRAG 的图行走）以及现在 agent 框架里标准的"想一想、检索、再想一想"模式的祖先。

端到端版本去掉了监督、让整个东西可微，也就是从那时起结果变弱、领域得出"显式记忆才是正路"这个结论的时候。那个结论大概是过早的——失败的不是显式记忆，而是*梯度训练的*显式记忆。

## 6. 强化学习里的情节记忆

这是最有资格说"这是*那个*计算结果"的分支，因为它产出了"遗忘能提升性能"的演示。

**Blundell, C., Uria, B., Pritzel, A., Li, Y., Ruderman, A., Leibo, J. Z., …
Hassabis, D. (2016).** Model-free episodic control. arXiv:[1606.04460](https://arxiv.org/abs/1606.04460)。

存下（状态、动作、回报），在决策时查最近的已存状态，取记录回报最好的那个动作。这是**非参数化 RL**：没有泛化，没有函数逼近，只有检索。它解开了 DQN 解不开的稀疏奖励 Atari 游戏，纯粹因为它能回忆起某一条侥幸的轨迹。

对记忆设计的意义：**一次性情节记忆能替代大量梯度下降**，而且恰好在奖励稀疏的地方——也就是预测误差信号稀少而巨大的地方。这是"一个 agent 需要情节存储，而且存储的职责是抓住罕见的、高价值的事件，而不是记录一切"最有力的实践论据。

**Pritzel, A., Uria, B., Srinivasan, S., Puigdomènech, A., Vinyals, O.,
Hassabis, D., … Blundell, C. (2017).** Neural episodic control.
arXiv:[1703.01988](https://arxiv.org/abs/1703.01988)。

把精确查找换成一个可微的、学出来的 key，从而能在相似状态间泛化，同时保留情节式的更新规则（快速的、非梯度的写入；较慢的、基于梯度的巩固进参数化策略）。这是互补学习系统在 RL agent 里最干净的实例化：一个写一次的快存储，和一个从它训练出来的慢存储。

**Yalnizyan-Carson, A., & Richards, B. A. (2022).** *Forgetting enhances
episodic control with structured memories*. *Frontiers in Computational
Neuroscience*, 16, 757244.
DOI [10.3389/fncom.2022.757244](https://doi.org/10.3389/fncom.2022.757244)。

已在 [01-human-memory.md](01-human-memory.zh-CN.md) 引过，这里重引，因为这才是它自然的位置。与情节控制同样的设置，但用一个有界的缓存和淘汰规则；发现是淘汰掉很大比例的结构化记忆没有代价，而且*一定程度的*淘汰由于压制了过时和罕至状态，优于无界记忆。

这个结果给了一个定量答案，回答每个生产记忆系统都在靠猜的问题：**该忘记多少？** 在这个设定里，远多于容量所要求的。

**Lengyel, M., & Dayan, P. (2007).** Hippocampal contributions to control:
The third way. *Advances in Neural Information Processing Systems* 20.

这是解释"为什么一个无模型 agent 需要一个介于无模型与有模型之间的第三系统"的框架论文：一个快速的、情节式的、非参数的存储，它支持**没有模型的基于模型的评估**。当有人问"我都有大上下文窗口了为什么还要记忆层"时值得引这篇——答案是上下文窗口就是模型，而模型每次查询都很贵。

## 7. 工作记忆作为计算资源

Cowan, N. (2001). The magical number 4 in short-term memory: A reconsideration
of mental storage capacity. *Behavioral and Brain Sciences*, 24(1), 87–114.
DOI [10.1017/S0140525X01003922](https://doi.org/10.1017/S0140525X01003922)。

在控制住组块和复述之后，容量上限约 4 个组块，不是 7±2。两个后果：限制是真实且小的；人类超出它的方式是**改变单位**，不是扩大缓冲。

第二条正是 AI 做错的。200k token 的上下文不是 200k 个单位的工组记忆——注意力随位置退化（Liu et al. 2023，*Lost in the Middle*），也随干扰密度退化（RULER，Hsieh et al. 2024）。有效容量小得多，而且和人类不同，它不会因组块化而改善，因为模型不自己选择单位。

**Oberauer, K., & Hein, L. (2012).** Attention to information in working memory.
*Current Directions in Psychological Science*, 21(3), 164–169.
DOI [10.1177/0963721412444727](https://doi.org/10.1177/0963721412444727)。

工作记忆对注意焦点而言*没有固定的槽位数*；绑定限制来自干扰，以及维持特征之间**绑定**的要求。容量限制关乎**关系的维持**，不是条目数。

直接推论：长上下文的代价不在于 token 数量，而在于模型必须保持一致性的**它们之间的关系**数量。这比上下文长度更好地预测 agent 何时开始退化，也是为什么"多塞点上下文"偏偏在需要跨大量实体保持一致的任务上失效。

## 8. 这个传统对了什么，又漏了什么

**对了，且基本被忽略的：**

*记忆的用途是在成本约束下被控制器查阅。* 三个架构都用匹配—检索—决策这个循环及其延迟预算来定义记忆。现代系统用存储来定义记忆，把成本模型留成隐含的，所以它们没有"检索够了没有"的有原则的概念。

*可及性是一个带历史的标量。* ACT-R 的基础激活值是领域里最成功的归约，而且它可以直接实现在向量库里，作为每次访问时更新的逐条目分数。

*写入触发条件就是设计。* SOAR 在僵局处组块化。ACT-R 在使用时强化。两者都不在"新输入到达"时写，而两者产出的知识库都与新奇度而非时长成正比。

*抽象必须替换实例。* 产生式编译是系统不再需要那些记忆的方式。没有它，记忆系统单调增长并退化——这正是 `Library Drift`（arXiv:2605.19576）在技能库里测到的失败模式。

**漏了，而现在正艰难地重新发现的：**

*规模与开放词表。* 这份文档里的每个架构都假设一个手工搭建的符号系统和一个封闭谓词集。没有一个能吞原始文本。这就是它们输掉的原因，而且这不是小事——自然语言的记忆表征问题是被嵌入（糟糕地）解决的，不是被块解决的。

*多主体与来源。* 它们都没有把记忆建模成在不同权限主体之间共享的东西。没有"这条记忆来自不可信来源"这个概念。

*删除。* 它们都没有删除机制，因为它们都没有对手，也没有一个有删除权的用户。

## 9. 桥：LLM 这一代接走了什么，又跳过了什么

从这些架构到 2026 年 agent 记忆的谱系不是一条直线，但其中三个部件被隐含地继承了，一个被整个丢掉了。

**接走的：** 存储/控制器的切分（上下文窗口就是工作记忆）；可及性作为一个标量（Generative Agents 的"近因 × 重要性 × 相关性"就是换了项的激活值）；阈值化检索（LongMemEval 里的"拒答"恰恰是 ACT-R 的检索失败）。

**丢掉的：****带冲突消解策略的程序性存储**。这正是技能库现在在重建的东西，也正是它们脆弱的原因。产生式系统按特异性和使用近因来消解冲突；技能库按与任务描述的嵌入相似度来消解，那是错的判据，会产生 `Library Drift` 记录的那种静默退化。

**从未尝试的：****在策略下从情节编译到程序**。没有任何主流 agent 框架有一个机制，让一条频繁被检索的情节变成一条规则并从此不再被检索。这是整个领域最清楚的未完成事项，而这份文档是把它直说出来的地方：

> 人的记忆与 agent 记忆之间的差距不是容量、不是检索质量、也不是上下文长度。差距在于人会**编译**：一个问题解决之后就变成一个过程，产生它的那些情节从此不再被需要。而 agent 记忆系统在堆积，不在编译。
